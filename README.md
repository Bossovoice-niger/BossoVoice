# BossoVoice - AI Voice for Sahel Farmers

Meta Llama Hackathon 2025 - Build for Your World
Track: Indie - Team: Bossovoice-niger (Bosso, Niger)

## Problem
2M farmers around Lake Chad lose crops. No info on Yumbu soil (black clay) and Gero millet. No AI speaks Hausa/Kanuri. Lake level changes daily.

## Solution
BossoVoice: Long-running Llama agent that:
- Monitors Lake Chad 24/7
- Speaks Hausa, Kanuri, French via WhatsApp voice
- Advises on Yumbu soil + Gero planting
- Works low-data for Bosso/Zinder

## How it Works
Lake Monitor -> Yumbu Knowledge -> Farmer Voice -> Llama Reasoning -> Voice Answer

## Demo
python agent.py --lang hausa

## Why We Win
Only team FROM Sahel FOR Sahel. Real farmer, real soil.
